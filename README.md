# test_modulpass.ch

Öffentliche Website des Modulpass, eines digitalen Produktpasses für Holzbaumodule.

Erreichbar unter https://samuelzueger.github.io/test_modulpass.ch/, später unter `modulpass.ch`.

Die Dateien werden mit `skripte/website.py` aus dem privaten Repository `Modulpass` erzeugt und nicht von Hand geändert. Sie enthalten nur öffentliche Angaben. Die Pässe sind Testpässe mit erfundenen Daten.

Die Bibliothek für den QR-Code auf der Startseite ist qrcode-generator von Kazuhiko Arase (MIT-Lizenz). Der Urheberhinweis steht in `index.html`.
